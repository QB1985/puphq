## What's new in 1.0.4

### Maneuver sets now belong to attachment sets
- The **Maneuvers** section moved from the config panel into the attachment sets tab, between the Head / Frame pickers and the attachments list.
- Every attachment set has its own maneuver sets. Choosing an attachment set switches to its maneuver sets (and the one that was on).
- Maneuver sets are numbered buttons: **+** adds another (up to 9) and **right click** removes one (there is always at least one). Your existing three sets are copied into each attachment set the first time.
- The maneuver dropdowns show each element's coloured circle.
- The minimized bar's `<` `>`, `/puphq manset next|prev|<number>` and the overload set's "Switch to" all work on the active attachment set's maneuver sets.

Install: copy the `puphq` folder to `Ashita\addons\` and run `/addon reload puphq`.
